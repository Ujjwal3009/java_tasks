# Java Tasks

All Java tasks for the mentoring program.

## Modules

- **task1-java-modules** - Java 9 modules, bank card stuff
- **task2-stream-api** - Streams, lambdas, predicates etc
- **task3-effective-java** - Effective Java exercises
- **task4-file-handling** - File I/O
- **task5-tdd-exercises** - TDD (FizzBuzz, bowling game, roman converter..)
- **task6-rest-api** - Spring Boot REST API with JPA and Swagger (multi module project)
- **task7-design-patterns** - Singleton pattern and Music Player
- **task8-spring-booking** - Spring event booking with XML config
- **task9-git-exercises** - Git exercises report

## Build

```
mvn clean install
```

Java 17, Maven 3.6+
